# 学习通（i.chaoxing.com）接入探测报告

> 阶段 0 探测的目标：在**动主代码之前**先确认登录策略与数据接口，避免按猜测实现。
> 方法：用程序自身的 WebEngine（已登录会话）+ Chromium 远程调试（CDP）在页面上下文里
> 抓真实请求、读真实响应。**本报告不含任何个人标识**（uid / fid / enc 等一律略去）。

## 1. 登录策略（实测）

| 项 | 实测结果 | 结论 |
| --- | --- | --- |
| 登录页 | `passport2.chaoxing.com/login?fid=…&refer=…&space=2` 返回 200（约 34 KB，服务端渲染） | 普通网页，程序里打开即可 |
| 登录方式 | 页面中「扫码」出现 8 次、「二维码」5 次、密码 6 次、手机号 3 次 | **支持扫码登录**（学习通 App 扫一下） |
| 密码处理 | 页面引用 `crypto-js.min.js`，`AES`/`encrypt` 出现 12+ 次 | 密码在**前端加密**后提交 → 我们**绝不复刻** |
| 验证码 | 引用 `//captcha.chaoxing.com/load.min.js`（独立域名），`captcha` 出现 15 次 | 密码登录可能触发验证码 → 人工过 |
| 登录接口 | `/fanyalogin`、`/fanyaloginbycode`、`/unitlogin`、`/org/searchUnis` | 都是页面自己调的，与我们无关 |
| 会话保持 | 登录后 `i.chaoxing.com/base` 直接可用（个人空间） | cookie 落在持久化 Profile 里，之后免登录 |

**结论**：登录完全交给 WebEngine —— 用户在程序里**扫码一次**，cookie 持久化，之后采集全在页面上下文完成。
不需要复刻密码加密、不接触验证码，也不保存密码。

## 2. 数据接口（实测）

站点把数据分散在多个子域，且**关键接口返回 HTML 而不是 JSON**：

| 环节 | 实测 | 形式 |
| --- | --- | --- |
| 取会话参数 `s` | 个人空间首页 HTML 里含 `visit/interaction?s=<32 位 hex>`（mooc1-1 的会话参数） | HTML 正则 |
| 课程列表 | `POST https://mooc1-1.chaoxing.com/mooc-ans/visit/courselistdata`，body `courseType=1&courseFolderId=0&baseEducation=0&superstarClass=&courseFolderSize=0` | **HTML** |
| 课程入口 | `…/mooc-ans/visit/stucoursemiddle?courseid=…&clazzid=…&vc=1&cpi=…&ismooc2=1&v=2` → **302** 到课程页 | 导航 |
| 课程页（新版） | `https://mooc2-ans.chaoxing.com/mooc2-ans/mycourse/stu?courseid=…&clazzid=…&cpi=…&enc=<课程级 32 位 hex>&t=…&pageHeader=0&v=2` | HTML |
| **作业列表** | `GET https://mooc1.chaoxing.com/mooc2/work/list?courseId=…&classId=…&cpi=…&ut=s&t=…&stuenc=<课程 enc>&enc=<另一个 32 位 hex>` | **HTML** |
| **考试列表** | `GET https://mooc1.chaoxing.com/exam-ans/mooc2/exam/exam-list?courseid=…&clazzid=…&cpi=…&ut=s&t=…&stuenc=<课程 enc>&enc=<hex>&openc=<hex>` | **HTML** |

### 两个决定性事实

1. **`enc` / `openc` 不在页面 HTML 里**（实测在课程页 HTML 中检索为空），是页面 JS 运行时生成的
   → **不要复刻它的算法**；让页面自己去发请求。
2. 接口横跨 `i.chaoxing.com` / `mooc1-1` / `mooc2-ans` / `mooc1` 多个子域，
   页面内 `fetch` 会被 CORS 拦下（实测两条候选接口直接 `Failed to fetch`）
   → 必须"**先导航到对应页面，再在当前页面里取数**"。

## 3. 推荐实现路线

**A（推荐）导航 + 让页面自己加载 + 在页面上下文里读结果**

1. 打开 `i.chaoxing.com/base`（登录态检查也在这里）→ 从 HTML 取 `s`；
2. 打开 `mooc1-1.chaoxing.com/visit/interaction?s=…` → 解析课程卡片（`courseid`/`clazzid`/`cpi`/课程名）；
3. 逐门课打开 `stucoursemiddle?…` → 重定向后得到带 `enc` 的课程页；
4. 在课程页点「作业」/「考试」标签（`pageHeader=8` / `9`），让页面自己带着 `enc/openc` 发请求；
5. 读取结果：注入脚本钩住 `XMLHttpRequest` / `fetch` 的响应拿服务端 HTML，
   或直接读标签容器里渲染出来的列表 DOM。

优点：不碰 `enc`、不改协议、与现有"页面上下文取数"架构一致；
代价：**要解析 HTML**（不像南大 LMS 那样有 JSON），每门课多 1~2 次页面加载。

**B 兜底**：只读渲染后的 DOM（更简单，但对 SPA 改版更敏感）。
**C 不建议**：复刻 `enc` 生成算法（改版即失效，且属于对抗性用法）。

## 7. 阶段 1 实现结果（2026-10-10 真机验证）

实现落在 `ChaoxingAdapter`（页面驱动状态机）+ `ChaoxingSyncRunner`（串行编排、写库）。
与探测结论的差异与补充如下。

### 7.1 与探测一致的部分

- 首页 → `s` → 课程中心 → 22 门课程链接 → 逐门 `stucoursemiddle` → 课程页（带 `enc`）；
- 点击「作业」后页面创建 iframe，其 `src` 即 `mooc1.chaoxing.com/mooc2/work/list?...`；
- 列表页为服务端渲染 HTML，解析可行：真机一次解析出 3 条作业（标题 / 状态 / 剩余时间 / 详情链接）。

### 7.2 与探测不同 / 新增的实测结论

1. **所有页面内容都由页面 JS 再渲染一步**：`loadFinished` 时刻直接读 DOM 会拿到骨架。
   实现上每个阶段都改为“轮询等待内容出现”（首页 token、课程中心链接、课程页「作业」入口、列表条目）。
2. **点击「作业」存在"点早了"**：入口 `span` 已出现但事件尚未绑定，第一次点击可能是空操作；
   实现上在拿到列表地址前每 2 秒补一次点击（最多 10 次）。
3. **点击可能让顶层页面直接跳转**（URL 出现 `pageHeader=8`）而不是创建 iframe；
   这会再触发一次 `loadFinished`，必须防止它再次点击（否则死循环）。
4. **新版课程页（AI 布局）**：部分课程顶层没有「作业」入口（实测有考试专用课与个别新版课）；
   入口轮询到超时也找不到时，判定为“该课程没有作业入口”，跳过并记 `parse_errors`，不算失败。
5. **「暂无作业」是权威空列表**：列表页会输出 `<div class="null-data">暂无作业</div>`；
   实现为“空结果且无 ParseIssue”，上层可安全软删本课程历史条目。完全读不出内容才记 Missing（禁止软删）。
6. **`pageHeader=8/9` 不能替代点击**：对 AI 布局课程，`pageHeader=8` 会被改写成 `21` 并嵌入
   `course-ans/ai/getStuAiWorkBench`，与作业列表无关。
7. **`enc` 不能自行拼接**：用课程页 URL 里的 `enc` 直接拼 `work/list` 会被拒绝（“无权限的操作！”），
   必须让页面自己点击生成第二个 `enc`。

### 7.3 真机结果

- 南大全量 13/13 后串行学习通：**成功 22 门 / 失败 0 / 跳过 0，用时约 75 秒**；
- 其中 1 门解析出 3 条真实作业（其余 21 门页面写明“暂无作业”）；
- iPad 前端 `scope=submitted` 混排输出：南大 7 条 + 学习通 3 条，均带 `source` / `sourceLabel`。

### 7.4 仍未验证 / 阶段 2 待办

- **分页参数**仍未确认：实现检测到“第 2 页及以后”的线索时把快照标记为不完整
  （保留旧数据、不软删），并在 `parse_errors` 记一条 `chaoxing.pagination`；
- **考试列表**（`exam-list`，带 `openc`）尚未接入；
- **作业说明（description）**：列表页不含正文，暂记 Missing；
- 学习通侧暂无增量策略：每次全量扫 22 门课（约 75 秒），与南大同步共用周期。
